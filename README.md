## 🌟 نبذة عن المشروع وفلسفته

منصة **أكاديمية خُطوة (Khutwa Academy)** هي منصة ويب تعليمية وتدريبية متقدمة مبنية باستخدام **React 19** و**Vite**، وموجهة لتمكين طلاب الجامعات وحديثي التخرج وخريجي الكليات النظرية في مصر والوطن العربي بالمهارات الرقمية والتطبيقية المطلوبة فعلياً في سوق العمل الحر (Freelancing) والتوظيف.

ترتكز فلسفة الأكاديمية على مبدأ:  
> **«واقعية كاملة وتطبيق عملي حقيقي.. بعيداً عن تجارة الوهم والوعود الخيالية»**

* معسكرات تدريبية مكثفة تعتمد على المشاريع التطبيقية بنسبة **100%**.
* إشراف وتوجيه مهني فردي أسبوعي **(1-on-1 Mentorship)** لمراجعة كل سطر كود وتصميم.
* تجهيز بورتفوليو احترافي حقيقي يؤهل المتدرب للمنافسة في السوق المحلي والعالمي.

## 🎯 أهداف دراسة الحالة (Case Study Brief)

* **القطاع وطبيعة النشاط:** تكنولوجيا التعليم والتدريب والتطوير المهني (EdTech / Vocational & Career Skills).
* **الجمهور المستهدف:** طلاب الجامعات الإقليمية، خريجو الكليات النظرية، والراغبون في إعادة التوجيه المهني (Career Shift).
* **المشكلة المعالجة:** إنهاء حالة التشتت والشك في جدوى الكورسات الإلكترونية التقليدية الناتجة عن الحشو النظري والوعود الخادعة، عبر تقديم مسارات تدريبية محددة المخرجات ومشاريع معلنة ومرشدين معتمدين.
* **النموذج التقني:** منصة استعراض مسارات متقدمة (Educational Programs Portfolio) مدعومة بنموذج تسجيل واستفسار ذكي مربوط بواتساب وسجل محلي لحفظ الطلبات والتواصل مع الطالب قبل بدء التدريب.

## ✨ المميزات وتجربة المستخدم (Key Features)

### 1. واجهة البداية ثلاثية الأبعاد (3-Zone Balanced Hero Section)
* **العنوان الرئيسي والـ CTA:** رسالة واضحة وقوية ترحب بالزائر مع زر توجيه فوري «شوف المسارات».
* **سلم التطور المهني (Stairs Motif):** أنميشن تفاعلي لدرجات السلم الست مع شعار الأكاديمية الذي يقفز نحو القمة.
* **مجسم الهاتف الرأسي التفاعلي:** فيديو تعريفي بجودة سينمائية مدمج داخل شاشة هاتف ذكي بإطار واقعي ومضيء (Ambient Glow) مع أزرار تحكم كاملة، كتم/تشغيل الصوت، شريط تقديم زمني، وترجمة نصية عربية متزامنة (CC).
* **مسار التدفق السهمي المضيء (Glowing Flow Connector):** سهم منحني ومتحرك يربط الهاتف بالسلم ليوصل الفكرة البصرية: «ابدأ من الهاتف، خذ أول خطوة، ثم اصعد تدريجياً حتى تصل للقمة».

### 2. التجاوب الكامل والشاشات الصغيرة (Responsive Order)
* توزيع رأسي ذكي متجاوب يضمن ظهور **العنوان أولاً**، ثم **سلم التدريب ثانياً**، ثم **فيديو الهاتف ثالثاً** دون أي تشويه أو تداخل.

### 3. لوحة تحكم الطالب (Student Dashboard)
* متابعة المعسكرات المشترك بها، نسبة الإنجاز والتقدم الأكاديمي.
* رصيد المحفظة التعليمية وإمكانية شحن الرصيد الفوري.
* نظام استفسارات مباشر للتواصل مع المرشدين وتلقي الإجابات.

### 4. لوحة تحكم الإدارة (Admin Dashboard)
* إدارة وتتبع بيانات الطلاب المسجلين والاشتراكات.
* مراجعة الاستفسارات الواردة، الرد عليها، وتحديث حالتها.
* فلترة الطلاب والاشتراكات والتحكم في تعيين كلمات المرور.

### 5. نظام الإشعارات الذكي (Notification Center)
* جرس إشعارات تفاعلي يعرض عدد الردود الجديدة فور ورودها مع ميزة التعليم كمقروء.

### 6. دعم الثيم المزدوج (Dark & Light Mode)
* تبديل فوري وسلس بين الوضع الليلي العميق والوضع الفاتح المريح للعين مع حفظ تفضيل المستخدم في `localStorage`.

## 🛠️ المكدس التقني (Tech Stack)

* **الواجهة الأمامية (Frontend):** React 19 (Hooks, Context API, Suspense).
* **أداة البناء والتطوير (Bundler):** Vite 6 (فائقة السرعة وتدعم HMR).
* **التنسيق والتصميم (Styling):** Vanilla Modern CSS + CSS Custom Variables (بدون اعتماديات ضخمة، مع أداء سلس ورشيق).
* **إدارة الحالة (State Management):** React Context (`KhutwaContext`) مع Custom Hooks (`useKhutwa`).
* **الأيقونات والخطوط (Assets & Fonts):** FontAwesome 6، خط **Cairo** للعربية، وخط **Poppins** للأرقام والمصطلحات.
* **الوسائط المتعددة (Multimedia):** مشغل فيديو HTML5 تفاعلي مخصص مع ملف ترجمات نصية `vtt` عربية.
* **التخزين المحلي (Persistence):** LocalStorage لمزامنة المستخدمين، الاستفسارات، التقييمات، والثيم.

## 🚀 التثبيت والتشغيل المحلي (Getting Started)

### 1. المتطلبات الأساسية
* تثبيت بيئة [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث).
* مدير حزم مثل `npm` أو `yarn` أو `pnpm`.

### 2. استنساخ المشروع
```bash
git clone https://github.com/eslamyf/Khutwa-Academy.git
cd Khutwa-Academy
```

### 3. تثبيت الاعتماديات
```bash
npm install
```

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح وتوجه إلى: `http://localhost:3000` أو المنفذ المحدد في الطرفية.

### 5. بناء نسخة الإنتاج
```bash
npm run build
```

## 🌐 النشر على Vercel (Deployment)

المشروع مُجهز بالكامل للنشر الفوري بنقرة واحدة عبر منصة **Vercel**:

1. ادخل إلى [Vercel Dashboard](https://vercel.com).
2. اختر **"Add New Project"** واستورد مستودع `Khutwa-Academy`.
3. سيتعرف Vercel تلقائياً على إعدادات Vite وملف `vercel.json` لمعالجة التوجيه الأحادي (SPA Rewrites).
4. اضغط **Deploy** وسيعمل الموقع مباشرة مع شهادة SSL مجانية وتوزيع عالمي عبر CDN.
