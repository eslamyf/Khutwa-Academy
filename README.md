# أكاديمية خُطوة | Khutwa Academy — منصة التدريب المهني والتعليم الرقمي

منصة تعليمية وتدريبية تفاعلية حديثة مبنية باستخدام **React 19** و**Vite**، ومخصصة لتمكين طلاب الجامعات وحديثي التخرج وخريجي الكليات النظرية في مصر والوطن العربي بالمهارات الرقمية الحقيقية والمطلوبة في سوق العمل والعمل الحر (Freelancing).

تعتمد المنصة على فلسفة **"واقعية كاملة بعيداً عن تجارة الوهم والوعود الخيالية"**، وترتكز على معسكرات تطبيقية بنسبة 100%، بناء مشاريع بورتفوليو حقيقية، وتوفير إرشاد مهني أسبوعي فردي **(1-on-1 Mentorship)** لكل طالب.

---

## 🎯 الأهداف ومحتوى البريف (Case Study Brief)

- **القطاع وطبيعة النشاط:** تكنولوجيا التعليم والتدريب والتطوير المهني (EdTech / Vocational & Career Skills).
- **الجمهور المستهدف:** طلاب الجامعات الإقليمية وخريجو الكليات النظرية الراغبون في التحول المهني لسوق العمل الرقمي.
- **حل المشكلة:** القضاء على حالة التشتت والشك في جدوى الكورسات عبر الإنترنت الناتجة عن الوعود المضللة والحشو النظري، من خلال تقديم خطط تدريبية تفصيلية واضحة، مشاريع عملية معلنة، وتجربة تقديم سريعة ومباشرة بنقرة واحدة.
- **النموذج التقني:** منصة استعراض مسارات متقدمة (Educational Programs Portfolio) مع نموذج تقديم واستفسار وحفظ بيانات، بدلاً من بوابات الدفع العشوائية المباشرة، لضمان مراجعة خلفية الطالب والتأكد من ملاءمة المسار له.

## 🚀 خطوات التثبيت والتشغيل المحلي

### 1. استنساخ المستودع أو الانتقال لمجلد المشروع
```bash
cd KhutwaAcademy
```

### 2. تثبيت الاعتماديات (Dependencies)
```bash
npm install
```

### 3. تشغيل خادم التطوير المحلي
```bash
npm run dev
```
سيعمل التطبيق على الرابط المحلي: `http://localhost:5173/`

### 4. فحص جودة الكود (ESLint)
```bash
npm run lint
```

### 5. بناء نسخة الإنتاج (Production Build)
```bash
npm run build
```
سيتم إنشاء حزمة الإنتاج المحسنة وفائقة السرعة داخل مجلد `dist/`.

### 6. معاينة نسخة الإنتاج محلياً
```bash
npm run preview
```

## 🌐 دليل النشر على Vercel (Deployment Guide)

المشروع مُهيأ بالكامل للنشر الفوري والسلس على منصة **Vercel**:

### الطريقة الأولى: عبر Vercel CLI (المباشرة)
```bash
# تثبيت Vercel CLI إذا لم تكن مثبتة
npm install -g vercel

# تسجيل الدخول والنشر
vercel
```
اتبع التعليمات السريعة في الطرفية؛ وسيتعرف Vercel تلقائياً على إطار عمل `Vite` وإعدادات البناء.

### الطريقة الثانية: عبر لوحة تحكم Vercel (Git Integration)
1. ارفع المشروع إلى مستودع على **GitHub** أو **GitLab**.
2. توجّه إلى [Vercel Dashboard](https://vercel.com/dashboard) واضغط على **"Add New Project"**.
3. اختر المستودع الخاص بأكاديمية خطوة.
4. الإعدادات الافتراضية المكتشفة تلقائياً:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. اضغط **Deploy**.

### معالجة التوجيه في تطبيقات الصفحة الواحدة (SPA Routing)
تم تضمين ملف `vercel.json` في جذر المشروع لإعادة توجيه جميع المسارات مثل `/programs` و`/programs/frontend` و`/contact` إلى `index.html` لمنع أخطاء 404 عند تحديث الصفحة:

```json
{
  "framework": "vite",
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

## 📱 التجاوب وتجربة المستخدم (Responsive & Accessible)

- تصميم متجاوب بالكامل 100% مع الهواتف الذكية والأجهزة اللوحية والشاشات العريضة.
- دعم كامل لاتجاه القراءة العربي **(RTL: Right-to-Left)**.
- دعم الوضع الليلي (Dark Mode) والوضع النهاري (Light Mode) مع حفظ تفضيل المستخدم في المتصفح.
- استمارة تقديم سهلة الاستخدام ومجهزة لأجهزة اللمس وأرقام الهواتف المصرية والدولية.
